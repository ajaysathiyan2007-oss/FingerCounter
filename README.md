
# Python Finger Counter

## Project Description
A real-time computer vision project that detects hands
and counts the number of fingers using a webcam.

## Technologies Used
- Python
- OpenCV
- MediaPipe

## Features
- Real-time hand detection
- Finger counting
- Webcam integration
- Supports two hands

## Installation

Install the required libraries:

pip install -r requirements.txt

## Run the Project

python finger_counter.py

## Exit
Press Q to close the webcam.
